# Firstlight Internship Board

A responsive internship listing interface built with HTML, CSS, and vanilla JavaScript—no frameworks or build tools required.

## Features

- Search internships by role, company, domain, or location
- Filter opportunities by domain
- Responsive layouts for mobile, tablet, and desktop
- Accessible form labels, keyboard focus styles, and a skip link
- Empty state with an option to clear filters
- Reduced-motion support

## Run locally

Clone or download the repository, then open `index.html` in a browser.

## Project files

- `index.html` — page structure
- `styles.css` — styling and responsive layouts
- `app.js` — sample internship data and interactive filtering

## Sample data

The internship listings are illustrative examples. Update the `internships` array in `app.js` to add or edit opportunities.
